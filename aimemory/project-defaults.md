# Project defaults

## When this applies

Use these defaults for actual projects created with OpenAI assistance. Do not
create a Git repository for everyday tasks, simple questions, or ordinary chat.
If the user gives a different project-specific instruction, follow that instruction.

## Default storage and history

- Keep a local Git clone plus a private GitHub repository.
- Use the owner's chosen local directory and approved repository; do not invent destinations.
- Never publish a repository or site without explicit approval.
- Commit coherent completed changes with short factual messages. Push after review.
- Preserve existing work, remote history, and tags. Do not force-push main.
- Use feature branches and pull requests for subsequent changes.
- GitHub receives only committed and pushed content; it is not automatic sync.
- Keep an independent backup for work that must survive account/device loss.
- Keep sensitive local configuration ignored and back it up separately.
- Remove duplicate ZIPs and disposable generated files when disk space matters;
  preserve source templates, scripts, documentation, and essential assets.

## Documentation and privacy

- Start from Proposal.md and the reusable project-template files.
- Default documentation language: en-US; provide pt-BR, es-AR, es-MX, es-ES,
  de-DE, and fr-FR documentation for these project templates.
- Keep application-specific template prompts in English unless explicitly changed.
- Include README, LICENSE and .gitignore. Record real sources and upstream licenses.
- Use demo data. Do not commit credentials, original settings exports, private notes,
  unapproved identities or personal filesystem paths, even in comments/history.
- Approved public attribution for this owner's projects: Cassio Henrique,
  Múltipla Tecnologia, mailto:cassiohenriqueofc@gmail.com. This is not blanket
  permission for other personal data. Reconfirm attribution for unrelated owners.
- Write concise, direct, factual prose. Avoid filler, unsupported claims, fabricated
  tests, invented sources, repetitive AI-generated commentary and secret values.
- State actual checks and untested limits. Keep dated changelogs and meaningful commits.
- Respect licenses. Noncommercial source-available is the selected default here;
  do not claim it is OSI open source or that it forces publication of private edits.

## Persistence boundary

This file is a portable memory note. It affects an assistant only when the note
or equivalent instructions are supplied/loaded. It does not modify account-wide
OpenAI settings. Install it in the intended memory vault and reference it when
starting a new project. Repositories generated by this starter include AGENTS.md.
