# Revised proposal — 0.1.3

## Problem and result

Maintain inspectable templates that turn page evidence into organized Markdown
through manual interpretation while retaining the content supplied by Clipper.
Package them as a versioned project that can be downloaded and reused.
The owner subsequently expanded scope to include a generic project starter,
seven documentation locales, attribution, memory rules and a repository/file map.

## Accepted scope

1. Three general JSON styles, prompt map, mock examples and documented limits.
2. README, license, ignore rules, privacy checks, scripts and a private Git history.
3. English templates and documentation for en-US, pt-BR, es-AR, es-MX, es-ES, de-DE and fr-FR.
4. Generated banner, static multilingual file map, local preview and metadata builder.
5. Reusable Proposal.md variable contract, README/license/ignore/note/code templates.
6. Project-only default: local Git clone plus private GitHub remote. No repositories
   for everyday tasks or simple chats. Portable aimemory and AGENTS instructions.
7. A sanitized ZIP, manifest and checksums in each private release.
8. A polished, multilingual README and site entry point, corrected repository naming,
   and social metadata prepared for the approved public GitHub Pages deployment and indexing.

## Publication and license decisions

The owner made this repository public and authorized GitHub Pages hosting and indexing. The site is configured at the approved project URL; confirm the first Actions run before claiming successful deployment.
The selected custom license prohibits commercial use without separate permission;
shared modifications retain source, attribution, license and dated change log.
It does not require publication of private edits or every private Git commit.
Only the public identity in .privacy-policy.json is expressly approved.

## Acceptance criteria

- [x] Three demo-safe templates and a no-AI fallback exist.
- [x] Manual execution, one structural quote prefix, fenced copyable text and
  interactive tasks outside fences are documented.
- [x] Full supplied content is retained by the template; extraction/transfer limits are disclosed.
- [x] All seven locales have README/guide, install, development, metadata, privacy,
  source/credit, license explanation, starter and storage instructions.
- [x] A fresh project can be rendered from reviewed public Proposal.md fields without overwriting a project; private body text is not copied.
- [x] Generated notes include flat YAML; JSON-LD omits unknown URLs instead of inventing them.
- [x] Original private exports and personal paths are excluded from source/release.
- [x] Local source and browser checks have defined, reproducible scope.
- [ ] User reviews template behavior with the real provider and installed extension.
- [ ] Windows, macOS and Linux end-to-end save tests.

Git push, release creation, CI outcome and repository-setting permissions are
recorded separately in project/release-checks.md and project/repository-protection.md.

## Deferred work

Specialist design-system templates, personal settings migration, automatic
second-vault copying, public hosting and external research remain deferred.
Do not treat scaffold generation as implementation of a new application's features.

## Focus and next step

There are now two tracks: the Web Clipper toolkit and the generic project starter.
The expansion came from explicit owner requests. Keep them in separate directories
and stop adding features until the owner completes the general-template review.
If the generic starter grows independently, split it into a separate Template
repository after review instead of duplicating the toolkit in every new project.

Next requested input: the owner's preferred general style and concrete capture
issues. Edit this proposal with those findings before authorizing the next phase.

Independent scope review found no unrequested drift. It recommended live capture review first, explicitly approved attribution, and metadata derived from actual delivered language files. The generator implements the latter two; live capture review remains with the owner.
